# GOLDHAIR

คลังประโยคและเครื่องมือค้นหาสัมผัสสำหรับนักแต่งเพลง

## เปิดใช้งาน

เปิด `index.html` ในเว็บเบราว์เซอร์ได้โดยตรง ข้อมูลที่บันทึกจะอยู่ใน Local Storage ของเบราว์เซอร์เครื่องนั้น ใช้ปุ่ม **สำรองข้อมูล** เพื่อส่งออกไฟล์ JSON และ **นำเข้า** เพื่อกู้คืนข้อมูล

## เผยแพร่ด้วย GitHub Pages

1. สร้าง Repository ใหม่ใน GitHub
2. อัปโหลด `index.html` และ `README.md` ไปไว้ที่โฟลเดอร์หลักของ Repository
3. เปิด **Settings → Pages**
4. เลือก **Deploy from a branch**, เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอ GitHub แสดง URL ของเว็บไซต์ในหน้า Pages

## หมายเหตุเรื่องออฟไลน์

การบันทึกและค้นหาข้อมูลทำงานในเบราว์เซอร์บนเครื่อง แต่ไฟล์รุ่นนี้ยังโหลด Tailwind CSS, ไอคอน และฟอนต์จาก CDN จึงต้องใช้อินเทอร์เน็ตเพื่อแสดงหน้าตาได้ครบ หากต้องการใช้งานแบบออฟไลน์โดยสมบูรณ์ ต้องเปลี่ยนส่วนตกแต่งให้เป็นไฟล์ภายในโปรเจกต์ก่อน

ข้อมูลใน Local Storage จะไม่ซิงก์ข้ามอุปกรณ์หรือข้ามเบราว์เซอร์ ให้ส่งออก/นำเข้า JSON เพื่อย้ายข้อมูล
